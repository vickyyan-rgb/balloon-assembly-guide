# 矮版圆石腕盒 · 自制弹簧按钮

8 个 STL 均以毫米为单位，按 100% 导入。下壳含套边高 19.5 mm；合盖接缝距底面 16.5 mm。两者均比上一次降低 10 mm。壳体合盖最高约 43.5 mm，另计外部按帽。底部带路宽 35、净高 5.6、覆盖长 18。使用本套配对的上盖和机架。

| 文件 | 用途 |
| --- | --- |
| 01 lower-shell、02 lid | 机架螺丝座、腰线套盖、绳孔和 Ø16.3 按钮安装孔 |
| 03 band-plate | 带子就位后将两肩粘在下壳凹位 |
| 04 equipment-carrier | 两块板的支承架、带扎带槽的 N20 座及卷筒护槽 |
| 05 D-spool | Ø18 × 8 卷筒，Ø3 D 轴，绕线宽 6 |
| 06 spring-holder | 胶合固定的弹簧座，穿盖筒 Ø15.8，外缘 Ø20.2，含两个独立的触点引线孔 |
| 07 button-plunger | 活动按帽，带压盘、弹簧导柱；自由滑动 |
| 08 guide-ring | 粘在弹簧座外缘，套住活动压盘，防止按帽弹出 |

## 先试按钮三件

1. 先打印 06、07、08。用细砂纸去除滑动面的毛刺。06 的大口向上，把金属压簧放入中央深孔。设计用外径 6 mm、自由长 8 mm、内径至少 3.8 mm、压并高度不超过 5 mm 的轻压簧。孔径 6.9；导柱 Ø3.3。这些是选配尺寸，用户原有弹簧尺寸未知。
2. 把 07 的小导柱朝下插进弹簧，从顶部将 08 套过按帽。用手按住环，试压回弹。机械行程约 1.8，装入后弹簧长度从约 7.4 缩至 5.6 mm。先试配，再粘。
3. 需要电气按键时，在 06 腔底两个小孔口分别贴一小片导电铜箔，分居弹簧两侧。每片单独引出一根细绝缘线；可先在壳外焊好铜箔，再装入。使触面平整，焊点避开滑动区。两片之间留绝缘间距，与金属弹簧绝缘。在 07 的压盘底面贴一条连续的 U 形铜箔，绕开中心弹簧、覆盖两个固定触点的位置；如果要允许按帽任意旋转，优先剪成完整导电环（约 Ø12 外径、Ø7.8 内径）。按下时铜环同时碰到两个固定触点，松手则断开。打印塑料和弹簧本身不承担开关导电功能。
4. 用通断档测两根引线：松开应断路，按到底应导通，转动按帽试几次。先断开电池、USB。确认后把 06 从盖外插入，用少量适配打印材料的胶粘外法兰底面。放入弹簧、07，在 06 法兰顶部最外圈（半径约 8–9.5 mm）薄涂胶并压上 08。胶不要流进孔内，不要粘按帽、触点和弹簧。固化后复测。两根引线分别接 Feather GPIO32 与 GND，沿用原常开按钮逻辑。

## 盒体装配

1. 先空配上下壳、底板和表带。0.4 mm 喷嘴可用 0.16–0.20 mm 起始层高。检查圆顶内表面、机架悬挑和按帽的支撑；清理 U 槽、D 孔和引线孔。导向环与固定座应先干装。
2. 下壳三个底孔和卷筒径向孔按 M2 攻丝。先去除切屑，再放入 60 × 36 × 7 的电池。电池保持水平，平面内转约 5°。薄的可移除胶用于电池定位。
3. 将 Feather ESP32 V2 和 DRV8833 放在机架底层支点，用薄绝缘胶带固定。按短焊线、无长排针设计。N20 用小扎带固定；卷筒对准 D 轴，用 M2 × 3 紧定螺钉压扁位，挡边与齿轮箱留约 1 mm。螺钉不可高出卷芯。将机架整体装入，用三颗 M2 × 5 盘头螺钉固定。确认螺钉和扎带不碰电池。
4. 将绳从左侧导孔引出，按钮线贴壁走，避开旋转件。让上盖垂直进入下壳套边。上下盖保持可拆。首次不挂绳，在桌面检查卡扣、触点和空载转动。

本设计按上版的名义零件、驱动板与电池尺寸计算。金属弹簧、铜箔、引线、按钮实际压力、材料和打印机公差需要试装；胶合前确认触点松开可靠复位。首次测试应在桌面进行。
