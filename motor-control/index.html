腕带电机遥控

1 · 上传固件

下载网页、固件和上传脚本 ZIP，解压后用 VS Code 打开包含 upload.ps1 的文件夹。在 PowerShell 终端列出串口，然后用腕带的实际端口替换 COM7。

.\upload.ps1 -ListPorts
.\upload.ps1 -Port COM7
Arduino IDE 安装步骤和接线说明

2 · 连接腕带 Wi-Fi

给 Feather 通电，在手机或电脑的 Wi-Fi 设置选择 Balloon-Motor，密码 PebbleRun27。出现「无互联网」时选择保持连接。

3 · 打开遥控器

连上腕带后打开下方地址。先用默认的 0.5 秒验证收放方向。

打开腕带遥控器

http://192.168.4.1/
