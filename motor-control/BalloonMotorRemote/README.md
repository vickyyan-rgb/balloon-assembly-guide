# 腕带电机遥控

适用 Adafruit Feather ESP32 V2、DRV8833 和单节锂电池供电的 N20。程序和网页分别位于同一文件夹的 BalloonMotorRemote.ino 和 page.h。使用支持 ledcAttach 的 Arduino-ESP32 3.x 或更新版。

## 安装

1. 拔掉 USB 和电池。IN1 接 Feather A1（GPIO25）。把 IN2 从 A2 移到 A0（GPIO26）。按钮用常开两脚接 GPIO32 和 GND，在此固件中用作停止。驱动板与 Feather 共地。
2. 电池断开，用 USB 上传本文件夹至板型 Adafruit Feather ESP32 V2。上传结束后固定电机，先卸下绳和卷筒，确认驱动能正常工作再带载。
3. 给腕带供电，手机或电脑连接 Wi-Fi **Balloon-Motor**，密码 **PebbleRun27**。在浏览器地址栏手动输入 **http://192.168.4.1/**。若提示无互联网，选择保持连接。
4. 设定 PWM 和时长后点一次方向键。网页停止键和腕带实体按钮都可提前停止。按下实体停止按钮时不会接受新动作。升起为顺时针，降落为逆时针，旋转方向从输出轴端看；如方向相反，断电后交换 OUT1/OUT2 两根电机线，或将程序里的 clockwiseUsesIn1 改为 false 再上传。

PWM 范围 1–100%，时长 0–25 秒，步进 0.1 秒，选 0 秒时电机保持停止，默认 40% 和 0.5 秒。速度滑块控制占空比，实际轴速受负载和电量影响。定时由板端执行，调滑块只影响下一次动作。机械行程和堵转电流没有传感器反馈。EEP/ULT 引脚的版本请按实物确认。

100% 对应 255/255 全占空比。使用标称 3 V 的 N20 时，请用独立限流 3.0 V 电源测试满速：先断开 BAT 到 VCC 的线，再由电机电源给 VCC 供电并与 Feather 共地。
